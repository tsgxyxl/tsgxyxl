# 姚心乐 | Xinle Yao

> 人物经历摘要 · Public profile

姚心乐（Xinle Yao），拥有数学、计算机与技术教学交叉背景。曾在 UNSW Sydney 学习并担任 COMP9021 Python 课程 Tutor，之后在悉尼从事技术、项目与产品管理工作，2023 年回到中国。

## 经历片段

- 教育：南京市南化第四小学、南京市扬子第一中学、上海市兰田中学、上海海洋大学。
- 教学：UNSW Sydney，COMP9021 Principles of Programming（Python）课程 Tutor。
- 职业：在悉尼承担技术经理、项目经理与产品经理职责。
